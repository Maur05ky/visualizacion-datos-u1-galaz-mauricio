## Definición

La integridad de datos es la propiedad que
permite mantener los datos completos, correctos
y consistentes durante su almacenamiento,
procesamiento y utilización.

Busca evitar modificaciones indebidas, pérdidas
de información y relaciones incorrectas entre
registros.

## Resumen personal

Entiendo que la integridad de datos permite
asegurar que la información se mantenga
correctamente registrada y relacionada.

Por ejemplo, en una base de datos de ventas,
cada venta debería estar asociada a un producto
existente.

Si se elimina un producto sin considerar sus
ventas registradas, podrían generarse
inconsistencias que afecten los análisis.

## Importancia

La integridad de datos es importante porque
ayuda a mantener la confiabilidad de la
información utilizada en los análisis y
visualizaciones.

Cuando existen registros incompletos, relaciones
incorrectas o modificaciones no controladas,
los gráficos pueden mostrar resultados que
no representan adecuadamente la situación estudiada.

## Características principales

- Integridad de entidad: permite identificar
  de manera única cada registro.
- Integridad referencial: mantiene relaciones
  válidas entre registros de diferentes tablas.
- Integridad de dominio: verifica que los
  valores cumplan las reglas establecidas.
- Consistencia: evita contradicciones entre
  datos relacionados.
- Protección frente a cambios indebidos:
  ayuda a conservar la información durante
  su utilización.

## Ejemplo de aplicación

Una empresa utiliza una base de datos con
tablas de clientes y ventas.

Cada venta contiene un identificador que
permite relacionarla con un cliente registrado.

Mediante reglas de integridad referencial,
se evita asociar ventas a clientes inexistentes,
mejorando la confiabilidad de los informes.
