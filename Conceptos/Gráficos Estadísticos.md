## Definición

Los gráficos estadísticos son representaciones visuales
de datos que permiten mostrar cantidades, distribuciones,
comparaciones, relaciones y tendencias mediante elementos
como barras, líneas, puntos y sectores.

Su objetivo es facilitar el análisis y la interpretación
de información numérica o categórica.

## Resumen personal

Entiendo que los gráficos estadísticos permiten transformar
datos en representaciones visuales que facilitan su comprensión.

Por ejemplo, si una empresa tiene registros de ventas de
diferentes meses, puede utilizar un gráfico de barras para
comparar los resultados o un gráfico de líneas para observar
cómo han cambiado las ventas durante el año.

Considero que seleccionar el gráfico adecuado es importante
porque no todos los gráficos sirven para representar el
mismo tipo de información.

## Importancia

Los gráficos estadísticos son importantes porque permiten
identificar tendencias, comparar cantidades, observar
distribuciones y detectar posibles valores atípicos.

También facilitan la comunicación de resultados a personas
que necesitan comprender la información sin revisar grandes
cantidades de registros.

Sin embargo, deben diseñarse correctamente para evitar
interpretaciones equivocadas o representaciones engañosas.

## Tipos principales de gráficos estadísticos

### 1. Gráfico de barras

Permite comparar cantidades entre diferentes categorías.

Ejemplo: comparar las ventas de distintas sucursales.

### 2. Gráfico de líneas

Permite representar cambios o tendencias a lo largo del tiempo.

Ejemplo: mostrar la evolución mensual de las ventas.

### 3. Gráfico circular

Representa proporciones de un total mediante sectores.

Ejemplo: mostrar la participación porcentual de diferentes
categorías de productos.

### 4. Histograma

Permite observar la distribución de datos numéricos
agrupados en intervalos.

Ejemplo: representar la distribución de edades de
un grupo de personas.

### 5. Gráfico de dispersión

Permite analizar la relación entre dos variables numéricas.

Ejemplo: observar la relación entre las horas de estudio
y las calificaciones obtenidas.

## Buenas prácticas

- Seleccionar el gráfico según el tipo de datos
  y el objetivo.
- Utilizar títulos y etiquetas comprensibles.
- Mostrar correctamente las unidades de medida.
- Evitar escalas que distorsionen los resultados.
- Utilizar colores de manera consistente y accesible.
- Evitar elementos decorativos innecesarios.
- Indicar la fuente de los datos cuando corresponda.

## Ejemplo de aplicación

Una empresa desea comparar las ventas de cinco
sucursales durante un mes.

Para ello, utiliza un gráfico de barras donde cada
barra representa una sucursal y su altura indica
el monto total de ventas.

Esta representación permite identificar rápidamente
qué sucursal obtuvo mayores ventas y cuáles
presentaron resultados más bajos.
