## Definición

Las herramientas de visualización de datos son
aplicaciones, plataformas y bibliotecas informáticas
que permiten transformar conjuntos de datos en
representaciones gráficas, como gráficos estadísticos,
mapas, diagramas y dashboards.

Su finalidad es facilitar el análisis, la exploración
y la comunicación de información mediante elementos
visuales.

## Resumen personal

Entiendo que las herramientas de visualización
permiten representar datos de una manera más sencilla
y comprensible, sin necesidad de revisar grandes
cantidades de registros.

Por ejemplo, una empresa puede utilizar Microsoft
Excel o Power BI para crear gráficos de ventas,
comparar resultados entre diferentes meses
y observar tendencias.

Considero que estas herramientas son importantes
porque permiten convertir datos en información útil
para comprender situaciones y apoyar decisiones.

## Importancia

Las herramientas de visualización son importantes
porque facilitan la exploración, interpretación
y presentación de datos.

Además, permiten automatizar la creación de gráficos,
integrar información de distintas fuentes y desarrollar
paneles interactivos.

Sin embargo, utilizar una herramienta tecnológica
no garantiza que una visualización sea correcta.
También es necesario considerar la calidad de los
datos, el diseño visual y las necesidades de los usuarios.

## Principales herramientas

### 1. Microsoft Excel

Permite organizar datos en hojas de cálculo y crear
gráficos estadísticos, tablas dinámicas y reportes.

### 2. Microsoft Power BI

Es una plataforma de inteligencia de negocios que
permite conectar distintas fuentes de datos y
desarrollar dashboards e informes interactivos.

### 3. Tableau

Es una herramienta orientada al análisis visual
de información mediante gráficos, dashboards
y representaciones interactivas.

### 4. Looker Studio

Es una herramienta que permite elaborar informes
y dashboards utilizando datos procedentes de
distintas fuentes.

### 5. Python

Es un lenguaje de programación que dispone de
bibliotecas como Matplotlib, Plotly y Seaborn
para crear visualizaciones de datos.

### 6. Obsidian

Es una aplicación para organizar conocimientos
mediante notas Markdown y enlaces internos.
Su vista de grafo permite visualizar las relaciones
entre notas y conceptos.

## Criterios para seleccionar una herramienta

- Tipo y cantidad de datos que se analizarán.
- Facilidad de uso.
- Posibilidad de crear gráficos interactivos.
- Compatibilidad con distintas fuentes de información.
- Necesidades de los usuarios.
- Costos y licencias.
- Opciones para compartir resultados.

## Ejemplo de aplicación

Una empresa necesita analizar las ventas realizadas
durante el año.

Para ello, utiliza Power BI para importar los
registros, organizar los datos y crear un dashboard
que presenta los ingresos mensuales, los productos
más vendidos y las diferencias entre sucursales.

De esta manera, los responsables pueden consultar
los resultados y detectar tendencias que apoyen
la planificación comercial.
