## Definición

Los datos estructurados son aquellos que se
organizan siguiendo un formato o esquema definido,
generalmente mediante filas y columnas.

Esta organización permite almacenarlos, consultarlos
y analizarlos de manera eficiente.

## Resumen personal

Entiendo que los datos estructurados son aquellos
que tienen un orden establecido y que podemos
encontrar fácilmente en tablas o bases de datos.

Por ejemplo, una empresa puede registrar el nombre
de sus productos, precios, cantidades y fechas
de venta en una tabla. Esto facilita buscar
información y realizar cálculos.

## Importancia

Los datos estructurados facilitan el procesamiento,
la comparación y el análisis de grandes cantidades
de registros.

En la visualización de datos, permiten construir
gráficos y dashboards a partir de variables
organizadas, siempre que los datos sean correctos
y adecuados para el análisis.

## Características principales

- Se organizan mediante un esquema definido.
- Pueden almacenarse en bases de datos relacionales.
- Facilitan las consultas mediante herramientas
  como SQL.
- Permiten realizar filtros, agrupaciones y cálculos.
- Son útiles para generar informes y visualizaciones.

## Ejemplo de aplicación

Una tienda registra sus ventas en una tabla
con las columnas: fecha, producto, categoría,
cantidad y precio.

Estos datos pueden utilizarse para crear gráficos
que permitan comparar ventas mensuales o
identificar los productos más vendidos.
