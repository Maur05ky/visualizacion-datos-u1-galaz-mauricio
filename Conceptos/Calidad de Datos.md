## Definición

La calidad de datos es el grado en que un conjunto
de datos cumple con las características necesarias
para ser utilizado de manera confiable. Incluye
aspectos como exactitud, completitud, consistencia,
actualidad y validez.

## Resumen personal

Entiendo que la calidad de datos es fundamental
porque no basta con tener mucha información si
esta contiene errores.

Por ejemplo, si una empresa registra ventas
duplicadas o cantidades incorrectas, los gráficos
pueden mostrar resultados equivocados y provocar
malas decisiones.

## Importancia

La calidad de datos permite que los análisis y
las visualizaciones representen correctamente
la realidad estudiada.

Cuando los datos son confiables, las organizaciones
pueden identificar tendencias, comparar resultados
y tomar decisiones con mayor seguridad.

## Características principales

- Exactitud: los datos representan correctamente
  lo que se pretende medir.
- Completitud: contienen la información necesaria
  para el análisis.
- Consistencia: no presentan contradicciones
  entre registros.
- Actualidad: están suficientemente actualizados
  para su propósito.
- Validez: cumplen con los formatos y reglas
  establecidos.
- Unicidad: evitan duplicaciones indebidas
  de registros.

## Ejemplo de aplicación

Una empresa desea elaborar un dashboard con sus
ventas mensuales.

Antes de generar los gráficos, revisa si existen
registros duplicados, fechas incorrectas o montos
vacíos.

Después de corregir estos problemas, puede
obtener resultados más confiables.
