# Conceptos Fundamentales de Visualización de Datos

**Estudiante:** Mauricio Galaz Morales  
**Asignatura:** Visualización de Datos  
**Institución:** INACAP

## Descripción

Este repositorio contiene el desarrollo de una evaluación académica sobre los conceptos fundamentales de visualización de datos. El trabajo utiliza Obsidian para organizar conocimientos mediante notas, enlaces internos y representaciones visuales.

## Contenido del proyecto

- 25 notas conceptuales relacionadas mediante enlaces internos.
- Mapa de contenido (MOC) y vista de grafo de Obsidian.
- Tres análisis críticos de visualizaciones reales.
- Ensayo sobre la importancia de la visualización de datos.
- Reflexión personal sobre el uso de Obsidian y GitHub.
- Mapa conceptual en desarrollo.

## Herramientas

- Obsidian
- Git y GitHub
- Markdown

## Objetivo

Comprender los fundamentos de la visualización de datos y desarrollar habilidades para organizar, relacionar y comunicar información de manera clara.
